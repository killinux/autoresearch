# autoresearch 项目文件清单

> 仓库根目录每个文件/文件夹是干什么的，一份给新手的速查表。
> 配合 [`代码解读.md`](代码解读.md) 和 [`architecture.html`](architecture.html) 一起看。

## 一句话总览

autoresearch 让 AI 当"自动调模型的研究员"：它反复**改 `train.py` → 训练 5 分钟 → 量 `val_bpb`（越低越好）→ 留好的 / 退坏的**，过夜跑上百次。整个仓库故意保持极小，**真正要改的只有 2 个文件**。

---

## 顶层文件逐个看

| 文件 / 目录 | 是什么 | 谁来改 |
|---|---|---|
| **`train.py`** | 🤖 **AI 改的就是这个**。完整的 GPT 模型 + 优化器（Muon + AdamW）+ 训练循环。架构、超参、批大小、模型大小……全是旋钮，随便调。 | **AI 智能体** |
| **`program.md`** | 🧑 **人改的就是这个**。给 AI 的"游戏规则 / 工作说明书"：怎么 setup、怎么跑循环、什么能改什么不能、怎么记账。本质是个超轻量 skill。 | **人类** |
| **`prepare.py`** | 🔒 **不许改**。一次性数据准备（下载 ClimbMix 网页文本、训练 BPE 分词器）+ 运行时工具（数据加载、**评测函数 `evaluate_bpb`**）。里面还锁死了固定常量：时间预算、序列长度、词表大小。这是"裁判"，定死了才公平。 | 谁都不改 |
| **`README.md`** | 项目介绍：是什么、怎么装、怎么跑、设计理念、各平台 fork 链接（Mac/Windows/AMD）。新手入口。 | 维护者 |
| **`pyproject.toml`** | 依赖清单（PyTorch 等）+ 项目元信息。**`program.md` 规定 AI 不许装新包**，只能用这里已有的。 | 维护者 |
| **`uv.lock`** | `uv` 包管理器锁定的精确依赖版本，保证每台机器装出来环境一致。自动生成，别手改。 | 自动生成 |
| **`analysis.ipynb`** | Jupyter notebook，用来读 `results.tsv`、画 `val_bpb` 随实验下降的曲线、分析实验进展。 | 人类（看结果时） |
| **`progress.png`** | README 顶部那张题图（teaser）。 | 静态资源 |
| **`docs/`** | 文档目录（你正在看的就在这里）。已有：本清单、`代码解读.md`、`architecture.html`（架构图+数据流图）、`windows-rtx4090-guide.md`。 | 人类 |

## 还有两个"跑起来才出现"的文件（不在上面的 ls 里）

| 文件 | 什么时候出现 |
|---|---|
| **`results.tsv`** | AI 跑实验时自己建的"实验账本"，每行一个实验：`commit / val_bpb / 显存 / keep-discard-crash / 描述`。**故意不提交 git**（留作 untracked）。 |
| **`run.log`** | 每次 `uv run train.py > run.log 2>&1` 的输出日志，结尾打印 `val_bpb` 等指标，崩溃时这里有 Python 报错。 |

---

## 核心记忆点

```
改模型 → train.py        （AI 动手）
定规则 → program.md      （人动手）
当裁判 → prepare.py      （谁都别碰）
看结果 → analysis.ipynb + results.tsv
```

> 设计哲学：**单文件可改、固定时间预算、自包含**。AI 只碰 `train.py`，diff 干净可审；训练永远 5 分钟，实验之间直接可比；除 PyTorch 外几乎没有外部依赖。
