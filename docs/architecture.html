1 · 自主研究循环

人类编辑 program.md 定义协议；AI agent 永久循环地编辑 train.py 并以 val_bpb 决定取舍。

① 改 train.py
agent 提出一个实验想法
改架构 / 优化器 / 超参
→
② 训练 5 分钟
uv run train.py
固定 TIME_BUDGET=300s
→
③ 评测
grep val_bpb
越低越好
④a 变好 → keep
保留 git commit
推进分支
④b 持平/变差 → discard
git reset 回退
记录到 results.tsv
↻ 回到 ①，永不停止（约 12 实验/小时，整夜约 100 个）
编辑代码 训练 评测（固定指标） 保留 丢弃
简洁性准则：同等效果下更简单更好；删代码还能持平/更好是最佳结果。第一次运行必须原样跑出 baseline。

3 · 数据流图

从原始 parquet 数据到训练梯度更新与评测指标的完整链路（prepare.py → train.py）。

① 数据下载
prepare.py
HuggingFace climbmix-400b-shuffle → parquet 分片下载到 ~/.cache/autoresearch/data。最后一片 shard_06542 固定作验证集。
↓
② BPE 分词器
rustbpe → tiktoken
训练 vocab_size=8192 的 BPE，存为 tokenizer.pkl；并生成 token_bytes.pt（每 token 的字节数，供 bpb 评测）。
↓
③ dataloader
make_dataloader
BOS 对齐 + best-fit 装箱：每行以 BOS 开头，贪心填入最大可放下的文档，放不下则裁切最短文档填满 → 100% 利用率、无 padding。输出 (inputs, targets) 已搬到 GPU。
↓
④ 前向 + 反向
梯度累积
凑够 TOTAL_BATCH_SIZE（≈524K tokens/步）；bf16 autocast；loss=NaN 或 >100 即 exit(1) 快速失败。
↓
⑤ 优化器更新
MuonAdamW
2D 矩阵参数 → Muon（Newton-Schulz 正交化 + NorMuon 方差归约）；embedding / lm_head / 标量 → AdamW。LR 按 1/√d_model 缩放，warmup→恒定→warmdown 调度。
↓ 循环至 total_training_time ≥ 300s（step>10 后才计时）
⑥ 评测
evaluate_bpb · 不可改
在验证分片上计算 bits-per-byte：Σ(每 token 交叉熵 nats) 按字节加权 → bits/byte，特殊 token（0 字节）排除。固定 MAX_SEQ_LEN 保证跨配置可比。
↓
⑦ 结构化输出
summary
打印 val_bpb / peak_vram_mb / mfu / num_steps …，agent 用 grep ^val_bpb: 提取关键指标，决定 keep / discard。
固定常量（prepare.py:30-32）：MAX_SEQ_LEN=2048，TIME_BUDGET=300s，EVAL_TOKENS=40×524288。这些与评测函数一同构成"不可改的裁判"，保证所有实验公平可比。
