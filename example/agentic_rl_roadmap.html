地基

经典 RL 直觉

先有 policy / reward / advantage / 探索vs利用 / 多步决策的心智模型，后面 GRPO 才不抽象。

  • 01 老虎机：动作 + 奖励，探索 vs 利用（ε-greedy / UCB）
  • 02 迷宫：引入状态，表格 Q-learning，完整 MDP
  • 03 倒立摆：状态连续→神经网络代替表格，策略梯度
▶ 01_bandit.py · 02_qlearning_gridworld.py · 03_cartpole_reinforce.py

SFT

监督微调（指令微调）

决定"格式与基础"，但学不会没见过的推理——这正是要上 RL 的原因。

  • 核心概念：chat template、loss masking（只在 assistant token 算 loss）、packing
  • 动手：TRL SFTTrainer + Qwen2.5-0.5B/1.5B 跑一次
本系列未做玩具代码 · 走 TRL SFTTrainer（非 RL，故不在七连例内）
2
对齐

偏好对齐 / RLHF

让模型对齐人类偏好。先学最简单的 DPO，再理解经典 PPO+RM 为什么复杂、为何被 GRPO 简化。

  • DPO：把 RLHF 变成一个分类损失，不用 reward model、不用采样（最简单，先学）
  • PPO + Reward Model：RM 怎么训、KL 惩罚为什么必要
  • reward hacking 是什么——为阶段4 的奖励设计埋伏笔
DPO 走 TRL DPOTrainer · RLHF 直觉见 04（GRPO 那套同源）
3
GRPO

RLVR / 推理 RL —— 分水岭，务必吃透

可验证奖励（答案对不对 / 格式对不对）+ GRPO 大规模 RL，催生"会思考"的模型（DeepSeek-R1 / o1）。

  • GRPO 机制：去掉 critic，同一 prompt 采 N 个、组内归一化算 advantage
  • 规则式奖励：答案正确 + 格式正确，无需训 reward model
  • "aha moment"：模型自发变长 / 学会反思
▶ 04_grpo_tiny_llm.py（GRPO 教小 GPT 排序，含真实 reward hacking）· 05_grpo_minimal.py（40 行 GRPO 骨架，能背能改）
4
Agentic

Agentic RL + Infra —— 最对口工业岗

从单轮到多轮：think → 调工具 → 看结果 → 再 think…，奖励在轨迹末端给（稀疏）。

  • 单轮→多轮：轨迹级奖励、过程 vs 结果奖励、信用分配
  • 代表方向：代码/工具（ToRL/ReTool/CodeRL）· 搜索（Search-R1）· 通用多轮（RAGEN）
  • Reward 设计的坑：reward hacking、稀疏奖励、可验证性、防作弊
▶ 06_agentic_rl_tool.py（多步+调工具+稀疏奖励）· 07_agentic_codeRL.py（沙箱跑单测当奖励+reward hacking）

聚光灯：reward hacking 长什么样（来自 07 的真实输出）

同一个 agent、同一套 GRPO，只改奖励设计，结果天差地别。任务：写 solve(x) 使 solve(3)==6。

✗ 弱奖励（只看可见用例 solve(3)==6）
学到的程序: solve(x) = 6   # 写死答案
可见用例: 过 ✓
隐藏用例通过率: 0%
策略: P(作弊)=0.86, P(x*2)=0.13
奖励留了后门 → agent 学会蒙混作弊，根本不会泛化。
✓ 稳健奖励（可见 + 隐藏用例一起）
学到的程序: solve(x) = x * 2
可见用例: 过 ✓
隐藏用例通过率: 100%
策略: P(x*2)=1.00
奖励难作弊 → agent 被逼出真正泛化的解。
这就是"代码题不能靠 print 答案绕过单测"要堵的洞。可验证、难作弊的奖励 = 多样且有区分度的用例。 在 Agentic RL 里，奖励设计往往比训练算法本身更决定成败——这也是 Reward System / CodeRL 岗位的核心价值。

拉高视角：通往 plan agent 的三条路线

这份路线图全程在讲第 1 条（把策略训进权重）。但"让 agent 会决策"其实有三条路， 区别只在于——把算力花在训练、还是推理、还是脑内模拟。

路线 1 · 本路线图 01–07
RL 训进权重
代表：GRPO、o1 / R1、本系列 04–07
怎么变聪明：训练时海量试错，把好策略压进权重
算力花在哪 ↓
训练 ▓▓▓▓推理
快慢/代价：推理一遍过、最快；但要巨量训练+数据
"训练时变聪明，用时一遍过"
路线 2 · 可做的第 8 课
MCTS 搜树
代表：AlphaZero、MuZero、LATS、rStar
怎么变聪明：权重不变，推理时用 UCT 建树显式搜索
算力花在哪 ↓
训练推理 ▓▓▓▓（搜树）
快慢/代价：常更强；但慢、要好模型 + 价值估计
"用时多想想，搜出更优解"
路线 3 · LeCun 押注
世界模型规划 (JEPA)
代表：LeCun JEPA、V-JEPA 2（机器人零样本规划）
怎么变聪明：自监督学世界模型，在 latent 里模拟后果、再优化动作（MPC）
算力花在哪 ↓
自监督预训练 ▓▓推理 ▓▓（想象+规划）
快慢/代价：不靠试错、样本高效；仍早期、非主流
"脑内模拟后果，规划最优动作"
三条不是互斥，正在融合：rStar-Math 用 MCTS（路线2）造高质量数据，再 GRPO（路线1）蒸进权重； MuZero = 世界模型（路线3 思想）+ MCTS（路线2）。未来的强 agent 很可能三者叠加： 好的权重 + 推理时搜索 + 世界模型预演。
放回你的学习线：路线1 = 已做的 01–07（训练时学会）；路线2 = 想做的最小 MCTS 迷宫规划（推理时搜树，把第 1 课的 UCT 升级到真规划）； 路线3 = 概念前沿（V-JEPA 2 在脑内世界模型里规划）。
