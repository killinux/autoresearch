二、概念缩写速查表

缩写 / 符号 → 英文全称 → 中文 → 一句话含义。按上面的分层归类。

① 基本框架（MDP 五件套）

符号/缩写英文全称中文一句话含义
AgentAgent智能体做决策、要被训练的那个家伙（就是"策略"）。
EnvEnvironment环境世界的规则；接收动作、返回新状态和奖励。
sState状态当前处境的完整描述（迷宫里=站哪格）。
oObservation观测智能体实际看到的（可能只是状态的一部分）。
aAction动作智能体能做的选择（上下左右 / 生成哪个token）。
rReward奖励环境对单步的即时打分，RL 唯一的学习信号。
πPolicy策略从状态到动作的规则 π(a|s)，RL 要学的就是它。
MDPMarkov Decision Process马尔可夫决策过程RL 的标准数学框架：⟨s, a, r, 转移P, γ⟩。
POMDPPartially Observable MDP部分可观测MDP看不全状态的 MDP（只有观测 o）。

② 回报与价值

符号/缩写英文全称中文一句话含义
GReturn回报从某步往后的（折扣）累计奖励，"这局总共得多少"。
γGamma / Discount factor折扣因子0~1，越小越"短视"；让未来的奖励打折累加。
V(s)State-Value function状态价值站在 s、按当前策略往后能拿的期望回报。
Q(s,a)Action-Value function动作价值在 s 做 a、之后按策略走的期望回报（Q表存的就是它）。
A(s,a)Advantage优势A = Q − V，"这个动作比平均好多少"，策略梯度的关键。
BellmanBellman Equation贝尔曼方程价值的递归关系：当前值=即时奖励+γ·后续值。
TDTemporal Difference时序差分边走边用 r+γV(s') 来修正 V(s)，不必等整局结束。
δTD errorTD 误差δ = (r+γV(s')) − V(s)，更新就是朝它的方向挪。

③ 学习与探索（横切）

符号/缩写英文全称中文一句话含义
αAlpha / Learning rate学习率每次更新朝目标挪多大一步。
—Exploration / Exploitation探索 / 利用RL 永恒矛盾：试新的 vs 用已知最好的。
ε-greedyEpsilon-greedyε-贪心以 ε 概率随机探索，其余时候选当前最优（例子01/02）。
UCBUpper Confidence Bound置信上界给没试过的动作加"乐观奖金"，更聪明的探索（例子01）。
HEntropy (bonus)熵（奖励）鼓励策略别太确定，保持探索、防过早收敛（例子04）。
τTrajectory / Rollout轨迹 / 采样一次从头玩到尾产生的 (s,a,r) 序列。
—Episode回合一局完整的交互（到终点/失败/超时结束）。
—Replay Buffer经验回放池存历史经验反复利用，提升样本效率（DQN 用）。
—Credit Assignment信用分配最后的好/坏结果，该归功/归咎于前面哪一步？RL 的难点。

④ 算法分类（看算法先看这三对）

缩写/术语英文中文一句话含义
Model-free / basedModel-free / Model-based无模型 / 有模型要不要先学一个"环境怎么变"的模型。多数RL是无模型。
On / Off-policyOn-policy / Off-policy同策略 / 异策略只能用"当前策略"产生的数据学(on)，还是能用旧/别人的数据(off)。
Value / Policy-basedValue- / Policy-based价值法 / 策略法先学价值再选动作，还是直接学策略。Actor-Critic 是两者合体。

⑤ 经典与现代算法

缩写英文全称中文一句话含义
SARSAState-Action-Reward-State-Action—on-policy 的表格法，按"实际下一个动作"更新Q。
Q-learningQ-learning—off-policy 表格法，按"下一状态最优动作"更新Q（例子02）。
DQNDeep Q-Network深度Q网络用神经网络代替Q表 + 经验回放，玩雅达利成名。
PGPolicy Gradient策略梯度直接对"动作概率"求梯度去优化期望回报的总称。
REINFORCEREINFORCE—最基础的策略梯度：用整局回报当信号（例子03）。
ACActor-Critic演员-评论家Actor学策略、Critic学价值当裁判，降低方差。
A2C/A3C(Asynchronous) Advantage Actor-Critic优势AC（并行）用优势A的Actor-Critic，A3C是多线程异步版。
TRPOTrust Region Policy Optimization信赖域策略优化限制每次策略更新幅度，稳但复杂。
PPOProximal Policy Optimization近端策略优化TRPO的简化版(裁剪)，又稳又好用，业界默认、RLHF常用。
GAEGeneralized Advantage Estimation广义优势估计在偏差和方差间折中地估计优势A，PPO标配。
DDPG/TD3/SACDeep Deterministic PG / Twin-Delayed / Soft AC—面向连续动作（机器人控制）的Actor-Critic家族。

⑥ 大模型的强化学习（后训练 / 对齐）

缩写英文全称中文一句话含义
RLHFRL from Human Feedback人类反馈强化学习用人类偏好训出奖励模型，再用RL(常是PPO)对齐LLM。
RMReward Model奖励模型学人类喜好、给模型回答打分的网络，当RLHF的奖励来源。
KLKL divergence (penalty)KL散度惩罚惩罚新模型偏离原模型太远，防训崩/胡说。
GRPOGroup Relative Policy Optimization组相对策略优化DeepSeek提出：同题生成一组答案，用组内平均当基线，免Critic（例子04）。
RLVRRL with Verifiable Rewards可验证奖励强化学习奖励改成"答案对不对"这类能自动判定的信号（数学/代码），如例子04。
DPODirect Preference Optimization直接偏好优化旁支：跳过奖励模型和RL，直接用偏好数据微调，更省事。

三、这些概念在四个例子里各自登场

概念不是背的，跑一遍代码就记住了。对照 example/README.md。

  • 01_bandit.py —— 动作 a、奖励 r、价值估计 Q、探索vs利用、ε-greedy、UCB。最干净，没有状态。
  • 02_qlearning_gridworld.py —— 新增 状态 s、MDP、Q(s,a)、贝尔曼/TD、γ、α、Q-learning。表格法的代表。
  • 03_cartpole_reinforce.py —— 新增 策略 π、神经网络逼近、回报 G、策略梯度、REINFORCE、基线/优势思想、episode。
  • 04_grpo_tiny_llm.py —— 新增 LLM 上的 RL、GRPO、组相对优势、熵奖励、可验证奖励(RLVR)、reward hacking。

一条主线串起来：动作奖励(01) → 加状态做表格(02) → 用网络学策略(03) → 搬到语言模型(04)。 再回看本仓库 autoresearch 的"改代码→看val_bpb→保留更好的"，会发现是同一种"试错→打分→迭代"的循环。
